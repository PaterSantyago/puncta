# Puncta documentation

[Product entry](../README.md)

Use Puncta to apply the typography rules of a selected locale.
This guide describes the unreleased functional version.

1. [Install the required packages](getting-started/installation.md).
2. [Process text or HTML](getting-started/text-and-html.md).
3. Read [compatibility and version status](compatibility.md).
